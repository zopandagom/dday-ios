# 개발 계획

프로젝트 소유 문서다. 작업 진행 방식과 완료 기준은 하네스 문서 [docs/harness/WORKFLOW.md](harness/WORKFLOW.md) 에 있다.

## 목표
- 10~20대 여성을 위한, 예쁘고 쓰기 쉬운 디데이 앱을 만든다.
- 완전 무료·광고 없음. 한국어·영어로 App Store 에 출시한다.

## 핵심 기능 (MVP)
| 영역 | 기능 | 기술 메모 |
|---|---|---|
| 디데이 | 추가·수정·삭제·목록. 정렬: 다가오는(남은 날 적은 순) → 세는 중(D+·1일째, 최근 시작 순) → 지난(최근 순) → 날짜 계산 불가 | SwiftData. 정렬·상태는 Core `DDayStatus`·`DDayListOrder` |
| 날짜 | 양력·음력 선택. 음력은 윤달 여부 선택 | 한국천문연구원 기준 음력 표(변환 범위는 PRODUCT §2). Foundation `.chinese` 달력은 중국 기준이라 쓰지 않음 |
| 반복 | 없음 / 매년. 양력 2/29 → 평년 2/28. 음력 매년: 그해 윤달이 없으면 평달, 30일이 없으면 29일 | 다음 날짜 계산은 순수 로직(Core) |
| 세는 방식 | D-day(남은 날) / D+(지난 날) / 시작일을 1일로 세기 | 날짜 차이는 Core `CalendarDay` 의 율리우스 일(JDN, PRODUCT §2)로 계산(시간대 영향 없음) |
| 이미지 | 내 사진(PhotosPicker, 사진 권한 없이) 또는 기본 배경. 카드 비율(3:2) 자르기. 사진이 없으면 폴더 색 기본 배경 | 3:2 JPEG(원본 메타데이터 없음), 압축본 긴 변 최대 1600px·썸네일 최대 400px(키우지 않음), `.externalStorage` |
| 폴더 | 기본 폴더 생일·가족·연인·기타 + 직접 만들기(이름·색·아이콘). 이름 변경·순서 변경·삭제(안의 디데이는 미분류로 옮기거나 함께 삭제) | 기본 폴더는 systemKey 로 저장해서, 이름을 바꾸기 전까지는 앱 언어에 맞춰 표시 |
| 알림 | 기본 7일 전·2일 전·당일, 오전 9시. 디데이마다 전체 끄기, 알림 날짜(30일 전·7일 전·2일 전·당일) 켜기·끄기(30일 전은 기본 꺼짐), 시간 변경. D+·1일째 디데이는 100일 단위·N주년 기념일 알림(디데이마다 켜기·끄기, 기본 켜짐). 알림에 썸네일 첨부, 누르면 상세 화면 | iOS 예약 한도 64개 → 가까운 순 최대 60개만 예약하고 앱 실행·앱 복귀·디데이 변경 때 다시 계산. 알림 날짜는 고정 4개(30일 전·7일 전·2일 전·당일), 켜진 날짜·꺼진 날짜를 V1 두 필드에 저장 (선택지 밖 값은 읽을 때 버림). 기념일 날짜·후보는 Core `NotificationPlanner`(PRODUCT §2) |
| 설정 | 기본 알림, 언어, 알림 권한 상태, 개인정보처리방침 | |
| 첫 실행 안내 | 2~3장, 마지막 장에서 알림 권한 요청 | |
| 다국어 | 한국어·영어 (알림 문구 포함) | String Catalog |
| 디자인 | 파스텔·다이어리 꾸미기(다꾸)·스티커 감성, 다크 모드 | 팔레트·폰트는 PRODUCT §2. 아이콘·일러스트·기본 배경은 사용자가 ChatGPT 로 만들어 넣는다 |

## 로드맵
| 단계 | 기간 | 목표 | 완료 기준 |
|---|---|---|---|
| 1. 핵심 로직 | 1~2일 | 날짜 값 타입, 한국 음력 변환기, D-day 계산기, 알림 계획기 | 윤년·연도 넘김·윤달·음력 30일 처리 단위 테스트 통과 |
| 2. 목록·추가·수정 | 2~3일 | 홈 목록, 추가·수정·삭제, 정렬 | 시뮬레이터에서 디데이를 만들고 고치고 지울 수 있음 |
| 3. 이미지 | 2일 | 사진 선택, 자르기, 압축·썸네일, 기본 배경 | 사진을 붙인 카드가 목록과 상세에 보임 |
| 4. 폴더 | 1~2일 | 기본 폴더 자동 생성, 직접 만든 폴더 관리, 폴더 칩 필터 | 폴더 추가·이름 변경·순서 변경·삭제 동작 |
| 5. 알림 | 2~3일 | 권한, 예약(가까운 순 60개), 다시 예약, 기념일 알림 문구(`PlannedReminder.milestone`), 썸네일 첨부, 눌러서 상세 열기 | 실기기에서 설정한 날짜·시간에 알림 수신 |
| 6. 디자인 입히기 | 3일 | 에셋 넣기, 애니메이션·햅틱, 다크 모드, 첫 실행 안내 | 라이트·다크 모두 디자인 기준대로 보임 |
| 7. 출시 | 2~3일 | 개인정보처리방침, 스토어 스크린샷(ko/en), TestFlight, 심사 | App Store 심사 제출 |
| 2차 | 미정 | 홈 화면·잠금 화면 위젯, iCloud 백업·동기화, 100일·1000일 기념일 자동 표시(화면 표시. 기념일 알림은 MVP 알림) | 미정 |

## 위험과 대응
| 위험 | 대응 |
|---|---|
| CI macOS 분 소진 (비공개 무료 플랜 2,000분, macOS 10배) | 문서만 바뀐 PR 은 CI 생략, lint 는 Ubuntu. 부족하면 셀프 호스트 러너나 레포 공개 검토 |
| iOS 로컬 알림 예약 한도 64개 | 가까운 순으로 최대 60개만 예약하고 앱 실행·복귀·디데이 변경 때 다시 계산. BackgroundTasks 로 보조 |
| 음력 변환 정확도 (한국·중국 음력이 다른 해가 있음) | 한국천문연구원 기준 표를 쓰고 알려진 날짜로 단위 테스트. 변환 범위(PRODUCT §2, 음력 2050-11-18까지) 밖은 입력을 막음 |
| 사진 용량으로 저장소·목록 성능 저하 | 압축본과 썸네일만 저장(원본은 저장하지 않음). 압축본은 별도 모델이라 목록이 읽지 않고, 목록은 썸네일만 사용 |
| `PhotosPicker` 는 PhotosUI 의 SwiftUI 뷰라 Feature 에서 import 하면 lint `system_framework_only_in_impl` 에 걸림 | Client `Photo` Impl 의 `PhotoPickerButton` 을 App 이 편집 화면 슬롯에 주입 (PRODUCT §2) |
| 디자인 에셋(ChatGPT 생성)이 늦게 들어올 수 있음 | 같은 이름의 자리 표시용 에셋으로 먼저 개발 |
